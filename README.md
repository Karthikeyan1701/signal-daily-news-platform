# SignalDaily 🗞️

A modern, high-performance news platform built with **React**, **Redux Toolkit**, and **Tailwind CSS**.

## 🚀 Tech Stack
- React JS (ES6+)
- Redux Toolkit
- React Router DOM
- Tailwind CSS
- Axios
- EmailJS
- Error Boundaries
- Lazy Loading & Code Splitting

## ✨ Features
- Category-based news browsing
- Pagination, filtering, and sorting
- Newsletter subscription
- Optimized performance with Suspense
- Production-grade error handling

## 🛠️ Setup Instructions

npm install
npm run dev
